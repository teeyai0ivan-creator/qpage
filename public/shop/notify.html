ตั้งกลุ่มแจ้งเตือนผ่าน LINE หรือ Telegram ได้มากกว่า 1 กลุ่ม — แต่ละกลุ่มเลือกเองว่าจะรับแจ้งเตือนเรื่องอะไร เช่น มีออเดอร์ใหม่ / เช็คบิล / ยกเลิกรายการ

📖 วิธีขอโทเคนและปลายทาง (LINE / Telegram)

LINE (Messaging API)

ℹ️ LINE ไม่มีช่องทางให้ระบบส่งข้อความเข้าบัญชี LINE ส่วนตัวโดยตรงแล้ว (LINE Notify ปิดบริการ 31 มี.ค. 2025) — วิธีที่ยังใช้ได้คือสร้าง OA แล้ว แอด OA เป็นเพื่อน ซึ่งคุณจะรับข้อความในแอป LINE ส่วนตัวตามปกติ เพียงแต่ผู้ส่งแสดงเป็น บัญชีร้าน (OA) ไม่ใช่เพื่อน ถ้าไม่อยากสร้าง OA ให้ใช้ Telegram แทนได้

  1. สร้าง LINE Official Account (LINE OA) ที่ manager.line.biz (ล็อกอินด้วยบัญชี LINE) แล้วตั้งชื่อ/รูปเป็นชื่อร้าน
  2. ในหน้าจัดการ OA → ตั้งค่า (Settings) → Messaging API → กดเริ่มใช้งาน Messaging API → เลือก/สร้าง Provider แล้วยืนยัน (ตอนนี้สร้างช่องทาง Messaging API จาก developers console ตรง ๆ ไม่ได้แล้ว ต้องเริ่มจาก OA Manager)
  3. เข้า developers.line.biz → เลือก Provider → เลือกช่องทาง → แท็บ Messaging API แล้ว
    • คัดลอก Channel access token (long-lived) มาวางในช่องโทเคน (ถ้ายังไม่มีให้กดออกโทเคน — โทเคนไม่มีวันหมดอายุ แต่ออกใหม่แล้วตัวเก่าจะใช้ไม่ได้ทันที) โทเคนไม่ได้อยู่ในหน้า OA Manager (หน้าที่แสดง Channel ID / Channel secret) ต้องเข้า Developers Console เท่านั้น — เช็กว่าถูกช่องด้วยการเทียบ Channel ID ให้ตรงกัน
    • เปิด Allow bot to join group chats (ค่าเริ่มต้นปิดอยู่ ถ้าไม่เปิดจะเชิญบอทเข้ากลุ่มไม่ได้)
    • ตั้ง Auto-reply messages และ Greeting messages เป็น Disabled (ไม่งั้นบอทจะตอบอัตโนมัติรบกวนในกลุ่ม)
  4. หา ปลายทาง ของกลุ่ม: เชิญบอทเข้ากลุ่ม → ตั้ง Webhook URL ชั่วคราวที่ webhook.site (ฟรี ไม่ต้องสมัคร) → ส่งข้อความใด ๆ ในกลุ่ม → เปิดดู JSON ที่ webhook.site จะเห็น source.groupId ขึ้นต้นด้วย C (แชทส่วนตัวได้ userId ขึ้นต้น U, ห้องหลายคนได้ roomId ขึ้นต้น R) → คัดลอกมาวาง แล้วปิด Webhook ได้

💡 อยากให้เด้งเข้าหา “ตัวเอง” หรือหัวหน้างานคนเดียว (ไม่เข้ากลุ่ม)? ให้แอด OA เป็นเพื่อน → พิมพ์ข้อความหาบอทในแชทส่วนตัว → เอาค่า userId (ขึ้นต้น U) จาก webhook.site มาวางในช่องปลายทาง ข้อความจะเข้าห้องแชท 1:1 กับ บัญชี OA ของร้าน (ชื่อ–โลโก้ร้าน) ไม่ใช่จากบัญชี LINE ส่วนตัวของคุณ — และต้องไม่ได้บล็อค OA ไว้ ไม่งั้นข้อความจะไม่ถึง

⚠️ โควตาข้อความ: แผนฟรีของ LINE ให้ประมาณ 200 ข้อความ/เดือน และข้อความแจ้งเตือนของเราเป็น push message ซึ่ง นับโควตา (ข้อความตอบกลับแบบ reply ไม่นับ) — ส่งหาคนเดียวก็เริ่ม 1 ข้อความต่อครั้ง ถ้ามีออเดอร์เยอะควรใช้ Telegram (ฟรี ไม่จำกัด) หรืออัปเกรดแผน

Telegram (Bot API)

  1. คุยกับ @BotFather → ส่ง /newbot → ได้ Bot token มาวางในช่องโทเคน
  2. สร้างกลุ่ม แล้วเพิ่มบอทเข้ากลุ่ม (ต้องตั้งบอทเป็นแอดมินถ้าจะส่งในหัวข้อ)
  3. เอา Chat ID ของกลุ่ม (ค่าติดลบ เช่น -1001234567890) จาก @userinfobot หรือดูจาก Webhook
  4. ถ้าส่งในหัวข้อ (Topic) ของกลุ่ม ให้ใส่ Topic ID ด้วย ไม่ใส่ก็ได้

ไม่แน่ใจว่าตั้งถูกไหม? กดปุ่ม ทดสอบส่ง ได้เลย — ถ้าผิดพลาด ระบบจะบอกสาเหตุที่ผู้ให้บริการตอบกลับมาให้ครับ
