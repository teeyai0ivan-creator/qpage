ตั้งค่าการแจ้งเตือน

ตั้งกลุ่มแจ้งเตือนผ่าน Telegram ได้มากกว่า 1 กลุ่ม — แต่ละกลุ่มเลือกเองว่าจะรับแจ้งเตือนเรื่องอะไร เช่น มีออเดอร์ใหม่ / เช็คบิล / ยกเลิกรายการ

📖 วิธีขอ Bot token และ Chat ID (Telegram)
  1. เปิดแอป Telegram → ค้นหา @BotFather → กด Start → พิมพ์ /newbot → ตั้งชื่อบอท → จะได้ Bot token (หน้าตาแบบ 123456789:AA…) คัดลอกมาวางในช่องโทเคน
  2. สร้างกลุ่มที่ต้องการรับแจ้งเตือน → เพิ่มบอทเข้ากลุ่ม (ค้นชื่อบอทที่ตั้งไว้) — ถ้าจะส่งในหัวข้อ (Topic) ต้องตั้งบอทเป็น แอดมิน ด้วย
  3. เอา Chat ID ของกลุ่ม: แชทกับ @userinfobot แล้วส่งต่อข้อความจากกลุ่มไปให้ หรือกด "เพิ่มเข้ากลุ่ม" — ค่าของกลุ่มจะเป็น ค่าติดลบ เช่น -1001234567890
  4. ถ้าส่งในหัวข้อ ให้ใส่ Topic ID ด้วย (ดูได้จากลิงก์หัวข้อ t.me/c/…/42) ไม่ใส่ก็ได้ = ส่งเข้าหลักของกลุ่ม

ไม่แน่ใจว่าตั้งถูกไหม? กดปุ่ม ทดสอบส่ง ได้เลย — ถ้าผิดพลาด ระบบจะบอกสาเหตุที่ Telegram ตอบกลับมาให้ครับ

ℹ️ ระบบนี้แจ้งเตือนทาง Telegram เท่านั้น เพราะ LINE ไม่มีช่องทางส่งเข้าบัญชี LINE ส่วนตัวโดยตรงแล้ว (LINE Notify ปิดบริการ 31 มี.ค. 2025) — Telegram ใช้ฟรีและไม่จำกัดจำนวนข้อความ
