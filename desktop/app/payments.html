ตั้งค่าการชำระเงิน

บัญชีรับเงินของร้าน + คีย์ EasySlip สำหรับตรวจสลิปอัตโนมัติ — ลูกค้าจะเลือก "โอนเงิน" ได้เมื่อตั้งค่าครบ กำลังโหลด… กำลังเชื่อมต่อ…
ช่องทางรับเงินของร้าน
กรอกพร้อมเพย์ หรือเลขบัญชีธนาคาร (หรือทั้งสองอย่าง) — ลูกค้าจะเห็นข้อมูลนี้ที่หน้าจ่ายเงิน
ตรวจสลิปอัตโนมัติ (EasySlip)
ใส่คีย์ API ของ EasySlip เพื่อให้ระบบตรวจสลิปการโอนอัตโนมัติ — ถ้าไม่ใส่ ลูกค้าจะเลือก "โอนเงิน" ไม่ได้ (เหลือชำระเงินสด) · เมื่อสลิปผ่านการตรวจ ระบบจะส่งออเดอร์เข้าครัวทันทีและติดป้าย "โอนแล้ว"
