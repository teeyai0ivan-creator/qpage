ตั้งค่าโปรแกรมพิมพ์

โปรแกรมนี้ใช้เป็นหน้าจอระบบร้านและเป็นตัวช่วยพิมพ์ให้มือถือ/แท็บเล็ต — ตั้งค่าครั้งเดียวแล้วใช้ได้เลย

เอกสารอื่น ๆ
เครื่องพิมพ์ที่เลือกต้องเป็นรุ่นที่ติดตั้งไดรเวอร์ใน Windows แล้ว · ถ้าเลือก “เครื่องพิมพ์เริ่มต้นของ Windows” ระบบจะใช้เครื่องที่ตั้งเป็นค่าเริ่มต้น
ม้วน 58/80mm: ให้ตั้งขนาดกระดาษในการตั้งค่าเครื่องพิมพ์ของ Windows ครั้งเดียว (Printer properties → Preferences → Paper size) แล้วเลือก “ตามที่ตั้งไว้ในเครื่องพิมพ์” — Windows จะไม่รับขนาดกระดาษที่โปรแกรมกำหนดเอง

การทำงาน

พิมพ์เงียบ (ไม่ขึ้นกล่องยืนยัน)
เปิด = กดเริ่มทำ/เช็คบิลแล้วพิมพ์ออกทันที · ปิด = แสดงกล่องพิมพ์ให้เลือกเอง (เหมือนใช้เว็บในเบราว์เซอร์)
รับงานพิมพ์ “ใบสั่งครัว” จากมือถือ/แท็บเล็ต
พนักงานกดเริ่มทำบนแท็บเล็ต → เครื่องนี้พิมพ์ให้ทันที (ต้องเปิดโปรแกรมค้างไว้และล็อกอินแล้ว)
รับงานพิมพ์ “ใบเสร็จ” จากมือถือ/แท็บเล็ต
กดเช็คบิลจากเครื่องอื่น → เครื่องนี้พิมพ์ใบเสร็จให้
รับงานพิมพ์ “ป้าย QR โต๊ะ” จากมือถือ/แท็บเล็ต
สั่งพิมพ์ป้ายจากเครื่องอื่น → เครื่องนี้พิมพ์ให้
เปิดโปรแกรมพร้อมเปิดเครื่อง
เหมาะกับคอมที่ครัว — เปิดเครื่องแล้วพร้อมรับงานพิมพ์ทันที
เปิดแบบเต็มจอ
ใช้กับจอที่ตั้งประจำครัว/แคชเชียร์ (กด F11 สลับได้ตลอด)
